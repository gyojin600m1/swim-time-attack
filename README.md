# 超・水泳タイムアタック 全5種目

スマホ / PC のブラウザで遊べる水泳タイムアタックゲーム。外部ライブラリなし。泳法の描画は `swimmer-v2.js` を共用。

| 種目 | プレイ |
|---|---|
| 🏊 自由形 | [freestyle/](./freestyle/) |
| 🛌 背泳ぎ | [backstroke/](./backstroke/) |
| 🦋 バタフライ | [butterfly/](./butterfly/) |
| 🐸 平泳ぎ | [breaststroke/](./breaststroke/) |
| 🏅 個人メドレー | [im/](./im/) |

- 操作: スマホ=画面タップ / PC=F・J・Space
- 本格スタート(短笛→ロングホイッスル→Take your marks→電子音)。フライングは一発失格
- 15m潜水ルール、バタ・平は両手同時タッチ、記録は端末内(localStorage)に保存

## 2026-11-06 更新

- バタフライの同時リカバリー、背泳ぎの上向きの顔・胸、平泳ぎの引きつけ→蹴り→伸びを操作に連動。
- メドレーの両手を一かきとして判定。早めの壁入力は予約し、壁へ到達してからターン・ゴール。
- 通常のリズムを連打より有利にし、浮上や平泳ぎの操作を案内。設定ボタンは48px以上。
- 保存失敗を成功表示しない。ランキングはページを最後まで取得し、表示中の自動更新は5分間隔。
- 既存の自己ベスト・全体記録は削除しない。速度調整前の記録も残るため、旧記録と新記録は同じ条件ではない。

開発確認: `node tests/swim-simulation.cjs`（外部通信・公開記録送信なし）。
